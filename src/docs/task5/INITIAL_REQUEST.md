# 과제 5 공통 최초 요청

## 프로젝트

* 프로젝트명: Afterwave
* 저장소: https://github.com/Lui-die-lui/afterwave
* 작업 브랜치: `assignment-5`
* 시작 버전: `task5-start`

## 개선 목표

기존 Afterwave 접근 로그 화면에 다음 기능을 포함한 다중 조건 필터를 추가한다.

* 사용자명 검색
* 자원 선택
* 판정 ALLOW/DENY 선택
* 최소 위험도 입력
* 여러 조건의 AND 결합
* 필터 결과 건수 표시
* 결과가 없을 때 빈 상태 안내
* 필터 초기화
* 새로고침 후 필터 상태 유지

## 완료 조건

1. `FIXED_TESTS.md`에 정의된 고정 검사 10개가 모두 PASS여야 한다.
2. AI A와 AI B는 같은 고정 검사 10개를 사용해야 한다.
3. 고정 검사를 삭제하거나 완화하면 안 된다.
4. 검사 입력과 기대값을 변경하면 안 된다.
5. 기존 Afterwave 기능이 정상적으로 유지되어야 한다.
6. 실제 개인정보와 비밀 환경값을 화면, 저장소, 문서에 포함하면 안 된다.
7. 작업 결과는 무로그인 공개 주소에서 확인할 수 있어야 한다.

## 작업 제한

* AI별 시간 상한: 45분
* AI별 사용자 요청 수 상한: 8회
* 요청 수는 사용자가 해당 AI에게 전송한 메시지 수로 계산한다.
* AI 내부의 파일 읽기, 명령 실행, 도구 호출은 사용자 요청 수에 포함하지 않는다.

## 변경 금지 범위

* 고정 검사 10개의 ID
* 고정 검사의 입력
* 고정 검사의 기대값
* 기존 로그 원본 데이터
* 기존 환경변수의 실제 값
* 과제와 관계없는 기존 화면 및 기능

## 결과 기록

각 AI는 다음 내용을 저장소 문서에 남긴다.

* 시작 버전과 종료 버전
* 실제 작업시간
* 실제 사용자 요청 수
* 고정 검사 실행 결과
* FAIL이 하나 이상 나온 실행 회차 수
* 변경한 파일
* 남은 문제 또는 완료 상태
