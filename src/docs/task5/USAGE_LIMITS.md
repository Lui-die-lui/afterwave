# AI 공통 사용 상한

이 상한은 AI A 작업을 시작하기 전에 고정했으며 AI A와 AI B에 동일하게 적용한다.

## 시간 상한

* AI A: 최대 45분
* AI B: 최대 45분

시간은 사용자가 최초 요청을 전송한 시각부터 AI의 최종 작업 보고를 받은 시각까지로 계산한다.

## 요청 수 상한

* AI A: 최대 8회
* AI B: 최대 8회

## 요청 수의 정의

사용자가 AI에게 전송한 메시지 한 건을 요청 1회로 계산한다.

다음 항목은 별도의 사용자 요청으로 계산하지 않는다.

* AI가 실행한 터미널 명령
* AI가 읽은 파일 수
* AI 내부 도구 호출
* 자동으로 실행된 테스트 수

AI의 질문에 사용자가 답변을 전송한 경우에는 요청 1회로 계산한다.

## 검사 실행 회차

고정 검사 10개 전체를 한 번 실행한 것을 검사 실행 1회로 계산한다.

10개 중 하나 이상이 FAIL이면 해당 실행을 오류 회차 1회로 계산한다.

한 실행에서 여러 검사가 실패해도 오류 회차는 1회다.

## 상한 초과 처리

상한에 도달하면 추가 구현을 중단하고 다음 내용을 저장한다.

1. 현재 저장소 버전
2. 마지막 검사 결과
3. 첫 번째 실패 검사
4. 남은 문제
5. 다음 작업자가 수행할 행동
